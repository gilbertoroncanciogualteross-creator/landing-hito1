A landing page for an investment platform. I built it to practice my HTML, CSS and JavaScript skills, which I need before moving on to Tailwind and advancing in my frontend career.

Live: https://landing-hito1.netlify.app/

- I learned how to structure spacing, typography, layout and colors in a real context.
- I learned how to properly build the different sections of a web page.
- I learned how to use external fonts, for example Google Fonts, in a project.
